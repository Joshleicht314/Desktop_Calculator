# Desktop Calculator 
## Overview
The goal of this project is to implement a open source desktop style calculator using mechanical key switches. Specifically, the inital firmware is to target RPN users using the excellent Free42 software.
This is a follow up to the RP42 project started in 2024 (See: )

## Project Status
10/24/2026 : Initial project commits with concept art

## Project Requirements:
- Must function as a standard numpad when requested
- Must send calculated numbers to the host computer when connected
- Must use mechanical switches with standard 19.05mm (0.75in) spacing
- Must use rechargeable battery (via usb)
- Must be able to run Free42
- Must be open source to allow for additional firmware and improvements\
- Must use USB-C to charge and communicate
- Must have battery life between charges greater than 7 days  

- May use replaceable battery (i.e. 18650)
- May use Bluetooth to communicate with computer
- May use a backlit LCD
